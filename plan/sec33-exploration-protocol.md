# 3.3 第一轮探索协议

**固定日期：2026-09-29；状态：分析前规则。**本轮生成派生结果与候选图，不撰写正式正文、不编译、不改3.2、训练或既定指标。所有新结果标为 derived / exploratory，不自动升级为论文结论。

## 问题与数据层级

- 覆盖美国四站2023年、三模型、12条有向迁移路径。考察目标站空间条件与当地训练基准差距的对应，以及同一目标站内源站表现差异与源—目标空间差异的对应。
- 站点指标直接来自2023年完整参考标签结果；图块指标来自独立128×128图块景观，两种空间支持范围不互相替代。
- ED：m/ha，4邻域异类共享边，外框和背景不计入；AREA_MN：ha，8邻域同类连通斑块；AI：0—100，4邻域同类邻接；PD：每100 ha斑块数，仅备查。连通斑块不等同于实际农业地块。
- 模型混淆矩阵行真实、列预测，0玉米、1其它、2大豆；标签/FRAGSTATS类别编号1玉米、2其它、3大豆。读取时验证，不以列位置猜测。

## 分组规则（不根据模型误差调阈值）

1. 每个目标站独立分组。主变量为景观级ED与作物类别级AREA_MN；AI仅作补充检查，不进行交叉分组。
2. 对可定义的有限特征值，以线性插值计算1/3、2/3分位点。按右闭区间分为低、中、高组：x≤q1，q1<x≤q2，x>q2。
3. 重复分位点去重，等于最大值且会产生空高组的切点不使用；空组不输出。相同数值不可拆开。保留两个有效组时标为低/高，一个组时标为全部；记录原分位点、实际切点与合并原因。
4. 真实缺类或指标不可定义的图块进入独立缺失组，保存缺失原因，不补零。AREA_MN有类但缺值、AI有类但不可计算须区分。缺失组参与CM闭合，但不伪装成有序分位组。
5. ED分组对两作物完全一致；AREA_MN和AI按玉米、大豆分别分组。每一套分组固定用于全部模型、三个源站及五次预测。
6. 保存图块归属、阈值、实际特征范围、图块数、有效像元及三类像元数/比例。不同站点的高组不代表相同绝对空间条件。

## 精度与退化

- 站内：组内测试CM求和后计算类别F1=2TP/(真实类像元+预测类像元)。跨站：每个源站折模型先汇总同组CM计算F1，再求五次均值和样本标准差（ddof=1）。不平均图块F1，不把五次预测拼成一次，也不使用delta_error_rate替代F1退化。
- DR=100×(同模型、同目标、同组站内F1−跨站F1五次均值)/站内F1。保留站内F1、跨站F1、DR及五次结果。站内基准≤0或F1分母为0时保留NA和状态；若五次有不可计算值，不悄悄以较少次数替代五次均值。
- 缺类组同时报告预测为该类的误分像元数。真实类为0但存在假阳性时F1=0；真实与预测均为0时F1不可计算。
- 所有分组（含缺失组）CM相加必须精确恢复每个站内汇总CM及每个跨站折CM；再算全站F1与既有summary对照，不能平均分组F1检查闭合。

## 描述性比较

- 保留低—高组的F1和DR对照及中组，不能只报期望方向。源站比较在相同目标站、指标、作物及组内进行，不跨目标混合分位组。
- 单独列出源—目标的各项有符号差值与绝对差值，不拼成复杂度或综合距离指数。对三个源站逐对检查“空间差异更小是否对应更高跨站F1”；保留一致、相反、并列/无效情况，计数仅为描述，不当作独立重复试验。
- AI与AREA_MN的冗余仅按站点和作物各算一次描述性秩相关（不算p值），并对照其分组结果；不进行大量相关检验、回归、显著性检验或变量重要性排名。

## 边界距离探索

本轮重新开放可用性核查，历史“不进入正文”决定仅指此前写作安排；本轮不决定是否正式纳入3.3。若当前数据身份、空间掩膜及距离定义足够清楚，则按原七距离带复用，不为取得结论改变带宽。

同一目标站、同一距离带比较站内汇总与每次跨站预测错误率，再汇总五次。分别报告带内错误率、该带像元占比、错误数量/错误份额、对总体错误率贡献与净新增错误。按真实作物筛选的错误率属于漏分相关错误，不能称类别F1；错误率差不是F1退化。不得仅凭带内错误率高就断言新增错误大部分集中在边界。
