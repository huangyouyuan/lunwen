# 论文项目背景

## 总问题

在数据源、年份、时序输入、类别体系和训练策略统一的条件下，三种时空深度学习模型的跨区域玉米—大豆识别性能有何差异？不同目标区域和迁移路径的泛化表现是否与地物组成及景观配置差异相对应？

## 主线

严格评价 → 受控比较 → 空间解释。以站内 OOF 建立基准，用完整目标站测试量化跨站性能，以配对检验确定模型差异，再从站点级与 Patch 级空间特征解释区域与路径差异。

## 逻辑链

```
站内 OOF 基准
    ↓
完整目标域测试量化跨站性能
    ↓
配对检验确定模型差异
    ↓
站点级空间特征解释路径差异
    ↓
Patch 级空间特征验证局部规律
```

## 两个层次

### 第一层：泛化性能评价（数据已就绪，已验证）

- 站内 OOF pooled 玉米 F1、大豆 F1、OA；五折 mean±std 说明稳定性
- 跨站：每源站 5 checkpoint 各预测完整目标站，36 路径 mean±std
- 退化 ΔF1 = 100 × (F1_OOF − mean F1_cross)
- Friedman + Wilcoxon–Holm，12 路径为配对单位，玉米/大豆分别检验

### 第二层：空间特征解释（主要亮点，数据待补）

空间特征 = 地物组成 + 景观配置

- 站点尺度：玉米/大豆/其它占比、ED、AREA_MN、AI → 解释目标站与路径表现
- Patch 尺度：同样指标；按特征分组汇总 CM 再算类别 F1，不直接平均 Patch F1

## 当前结果方向（2026-09-18，已验证）

- 站内：U-TAE ≈ 3D U-Net > ConvGRU；玉米 F1 略高于大豆 0.6–0.9 pp；C 站最难、A 站最易
- 跨站：模型排序与站内一致，玉米、大豆一致；Holm 校正后 3D U-Net 与 U-TAE 无显著差异
- 退化：72 个值全为正，0.44–7.39 pp；ConvGRU 退化最小但站内基准最低，跨站绝对 F1 仍最低
- 路径：涉及 B 站的路径最难；存在方向不对称（ConvGRU 大豆 B→D 7.39 vs D→B 3.36 pp）

## 主指标

玉米 F1、大豆 F1，分别报告；OA 辅助。Crop-mIoU、三类 mIoU、其它类指标仅作补充，不控制正文结构。

## 两个贡献

1. 严格可追溯的跨区域评价：站内 OOF + 完整目标域测试 + 路径配对统计
2. 站点—Patch 两尺度空间特征解释：地物组成 + 景观格局 + Patch 局部特征
