# 论文项目背景

## 总问题

在数据源、年份、时序输入和训练策略统一的条件下，三种时空深度学习模型的跨区域玉米—大豆识别性能有何差异？不同目标区域和迁移路径的泛化表现是否与地物组成及景观配置差异相对应？这些差异在Patch内部和距类别边界不同位置上如何表现？

## 主线

在严格跨区域评价的基础上，从区域空间特征角度解释时空深度学习模型玉米—大豆分类的泛化差异及其局部误差表现。

## 逻辑链

```
严格OOF建立站内基准
        ↓
完整目标域测试量化跨区域性能
        ↓
配对检验确定模型差异
        ↓
站点级空间特征解释区域和路径差异
        ↓
Patch级空间特征验证局部误差规律
        ↓
距离边界分析解释空间特征如何转化为错误
```

## 三个研究层次

### 第一层：泛化性能评价

- 站内 OOF 基准（汇总混淆矩阵）
- 跨站 5 checkpoint 对完整目标站预测均值
- 主指标：Crop-mIoU = (IoU_corn + IoU_soybean) / 2
- 补充：三类 mIoU、其它类 IoU
- 模型差异检验：Friedman → Wilcoxon 两两 → Holm 校正

回答：哪个模型跨区域表现更好，差异是否稳定？

### 第二层：空间特征解释（主要亮点）

空间特征 = 地物组成 + 景观配置

**站点尺度**：玉米/大豆/其它占比、ED、AREA_MN、AI → 解释目标站和迁移路径表现

**Patch 尺度**：同样局部指标 + ΔER_p = ER_cross,p − ER_within,p → 检查同站点内部局部特征与泛化退化的关系

回答：为什么某些目标区域、迁移路径和局部 Patch 更困难？

### 第三层：距离边界分析

- 7 距离带像元占比、站内/跨站误差率、ΔER(d)
- 各距离带对总错误的贡献
- 玉米—大豆、玉米—其它、大豆—其它交界

回答：额外错误集中在边界附近，还是也进入地块内部？

## 两个主要贡献

1. **严格可追溯的跨区域评价体系**：站内 OOF + 完整目标域测试 + 路径配对统计
2. **站点—Patch—边界三尺度空间特征解释框架**：地物组成 + 景观格局 + 局部 Patch 特征 + 距边界错误
