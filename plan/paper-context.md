# 论文项目背景

## 研究问题

面向跨区域作物遥感制图场景，比较不同时空深度学习模型的空间泛化能力差异，揭示影响泛化性能的关键因素。

核心科学问题：
1. 三种典型时空建模范式（时间注意力、三维卷积、递归门控）在站内分类中性能差异多大？
2. 模型离开训练区域后，精度退化程度是否与模型结构有关？
3. 区域空间格局差异（景观破碎度、边界密度）如何影响跨区域泛化？
4. 分类误差在地物边界的空间集中分布规律如何？

## 研究对象

- 美国中西部玉米带 4 个典型农业站点（A、B、C、D）
- 分布于爱荷华州、印第安纳州、明尼苏达州
- 单站点空间范围约 77 km × 77 km

## 分类类别

| 类别 | 说明 |
|------|------|
| 玉米（Corn） | CDL 原始类别 |
| 大豆（Soybean） | CDL 原始类别 |
| 其它（Others） | 除玉米大豆以外的农作物和非农作物地类 |

## 数据源

- **遥感数据**：HLS v2（Harmonized Landsat and Sentinel-2）
  - 空间分辨率：30 m
  - 光谱波段：6 波段
  - 时间范围：DOY 116–266（主要生育阶段）
  - 时间分辨率：5 天（线性插值后）
  - 时间步数：31
  - 影像大小：2560 × 2560 像素 / 站点
  - 样本图块：128 × 128 像素，无重叠，每站点 400 个

- **标签数据**：USDA NASS CDL 2023

- **物候参考**：USDA Crop Progress Report

- **景观分析**：CDL 2021–2024 多年平均 + FRAGSTATS 4.3

## 模型

| 模型 | 时空建模范式 | 核心机制 |
|------|-------------|----------|
| U-TAE | 时间注意力 | 2D 空间编码 + L-TAE 时间注意力 + 2D 解码 |
| 3D U-Net | 三维卷积 | 3D 卷积编码-解码，时空联合建模 |
| ConvGRU | 递归门控 | 2D 卷积 + GRU 门控递归 |

## 实验设计

1. **站内分类**：5 折交叉验证，评估基础分类能力
2. **跨站点空间泛化**：源站点训练 → 直接迁移至目标站点（不微调）
3. **泛化退化分析**：以站内精度为参照，计算 mIoU 降幅
4. **边界距离分析**：形态学膨胀腐蚀生成 2 像素边界缓冲区，分析边界 vs 内部精度差异

## 指标

mIoU、Macro UA、Macro PA、Macro F1、Kappa、Overall Accuracy
