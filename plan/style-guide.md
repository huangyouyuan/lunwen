# 写作模式指南

从旧稿提取的作者写作习惯，AI 写作时必须参照。

## 总体风格

- 正式学术中文，措辞审慎
- 段落以连续论述为主，不使用列表替代正文
- 句子长度适中，不过短也不过冗长
- 先总后分的组织方式
- 数据描述客观，不使用夸张措辞

## 引言写法

- 以研究意义开篇，逐步聚焦到具体问题
- 文献综述按技术路线组织，不逐篇罗列
- 末段明确"本研究将……"引出目标
- 研究内容使用编号列举：（1）……（2）……
- 旧稿示例："粮食安全关系到人类社会的稳定发展，而准确获取主要粮食作物的空间分布信息是农业监测和粮食安全评估的重要基础"

## 数据比较句式

旧稿常见模式：
- "X 的 mIoU 最高，为 90.86–91.36%；Y 最低，为 86.98–87.80%"
- "同一站点内三模型的 mIoU 差值普遍小于 1 个百分点"
- "相较于站内分类，三种模型在跨站点应用中均出现精度下降"
- "3D U-Net 的平均 mIoU 降幅为 13.62 个百分点"

特征：
- 先给整体趋势，再给具体数字
- 使用"个百分点"区分百分比变化
- 比较时给出参照基准

## 结果描述

- 段首概述本段要讲什么
- 中间给出数据对比
- 段尾给出简要解释或指向后续分析
- 旧稿示例："统计结果表明，三种模型在内部纯净像元上的平均 mIoU 为 84.47–89.72，而在边界像元上仅为 42.73–44.31"

## 图表引用

- 首选："如表 2 所示""根据表 2""如图 1 所示"；句中括注"（表 2）"
- 备选："表 2 给出了……"
- 图表在正文中先引用，后出现
- 解释引出：确定归因用"这是由于"，推测用"这可能与……有关"；不用"这是因为"堆叠

## 参考论文的写法（`bibliography/writing-style-report.md`）

五篇同领域中文核心期刊论文的摘录与分析在该报告中。用法：
- 学的是**概念阐述方式**（泛化能力怎么定义、迁移怎么称呼）和**结果段从数字到解释的衔接**
- 不照搬呈现形式：本文的退化差值、热力图、中文角标不变
- 结果段结构：段首引表 + 总判断 → 逐模型/逐作物数字 → 段尾解释（盖爽、张冬韵、黄健熙三篇一致）
- 模型比较措辞：接近写"相差不大"，检验后写"差异显著""无显著差异"，弱者用"而"引出

## 方法描述

- 对模型结构的描述偏详细，包含数学公式
- 采用"由……组成"、"通过……实现"等结构
- 旧稿示例："U-TAE 由二维空间编码器、轻量级时间注意力编码器和空间解码器组成"

## 过渡方式

- 不使用机械过渡词
- 通过逻辑关系自然衔接："在……基础上，本文进一步……"
- 通过结果引出问题："上述结果表明……这一现象提示……"

## 禁止的表达

- "本文创新性地提出……"（除非确实有创新）
- "值得注意的是"（除非真正值得注意）
- 过度使用"首先、其次、再次、最后"
- "综上可知"在非总结位置使用
- 空壳强调句
- 翻译腔："统计学上的显著差异"→"差异显著"；"基于……的……"堆叠；"进行……处理"可直接用动词

## 中文化程度（2026-09-19 用户要求）

论文定位是普通中文核心期刊短文，读者不假定熟悉英文术语。

- 公式角标用中文，且按汉语语序把定语放前面：$F1_{\text{站内玉米}}$、$F1_{\text{跨站大豆}}$、$\Delta F1_{\text{玉米}}$；不写 corn / within / cross，也不写"玉米,站内"这种带逗号的并列
- 每个 equation 环境只放一个公式、一个编号；不用 `\quad` 把几个公式挤在一行
- 公式中的指标名保留通用缩写（F1、OA），Precision / Recall 写成中文"精确率""召回率"或用 $P_i$、$R_i$ 并在文中定义
- 正文术语：站内、跨站、泛化退化、五折均值、汇总混淆矩阵、迁移路径、源站、目标站
- 保留英文的只有：模型名（U-TAE、3D U-Net、ConvGRU）、数据产品（HLS、CDL）、通用指标缩写（F1、OA）、软件名（PyTorch、FRAGSTATS）
- "fold""checkpoint""OOF"在正文用"折""模型""交叉验证汇总"表达；首次出现可括注英文
- 表格列名、图轴标签、图例同样中文
- 句子直白：先给结论，再给数字；一句话说一件事
