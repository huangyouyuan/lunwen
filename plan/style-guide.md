# 写作风格指南

本文件是正文写作的唯一风格规范。格式规范在 `plan/format-spec.md`，论点在 `plan/claims.md`。

## 定位

普通中文核心期刊（测绘通报）短文。读者不假定熟悉英文术语。写作要通俗但精确——每句话读者看完能知道说了什么事实、这个事实支撑什么判断。

## 语言

### 中文优先

- 正文术语用中文：站内、跨站、泛化退化、五折均值、汇总混淆矩阵、迁移路径、源站、目标站、折间标准差
- 公式角标用中文，定语在前：$F1_{\text{站内玉米}}$、$\mathrm{DR}_{\text{玉米}}$；不写 corn / within / cross
- "fold"→折，"checkpoint"→模型/预测，"OOF"→交叉验证汇总；首次出现可括注英文
- 保留英文的只有：模型名（U-TAE、3D U-Net、ConvGRU）、数据产品（HLS、CDL）、通用指标缩写（F1、OA）、软件名（PyTorch、FRAGSTATS）
- 表格列名、图轴标签、图例同样中文

### 数字格式

- 百分数保留两位小数：90.98\%
- 差值用"个百分点"：1.61 个百分点（不是 1.61\%）
- 区间用 ～：90.98\%～96.23\%
- 每个数字都要带口径，读者能知道怎么来的："12 组实验（3 种模型×4 个站点）的玉米 F1 折间标准差"，不说"各模型在各站点的标准差"

## 行文原则

### 为论点服务，不白描

每个数字后面跟它说明什么。不为论点服务的数字删掉或放表里。不说"较高的""较为接近"这类空话——直接给范围，让读者自己判断。

### 主语写全、指代明确

- 说"三种模型的跨站玉米 F1 均值"，不说"精度"或"结果"
- 说"ConvGRU 在 B→D 路径上的大豆 F1"，不说"它"/"该值"
- 比较要说清对象和方向："U-TAE 比 ConvGRU 高 1.66 个百分点"，不说"明显更高"

### 结论限定范围

本文四站、不微调、F1 口径。不说"该模型泛化能力更强"，说"在本文四个站点的 12 条迁移路径上，该模型的跨站玉米和大豆 F1 均值更高"。

## 段落结构

### 结果段

- 段首：引图表 + 总判断（一句话概括本段论点）
- 中间：支撑数字，按逻辑分层（不是按表格行序逐行复述）
- 段尾：收回论点，或引出下一段的问题

### 同一节内多段组织

- 第一段讲模型之间的共性（共同趋势、共同规律）
- 第二段讲模型之间的差异（谁优谁劣、幅度多大、用图举例）
- 不在一段里既讲同又讲异

### 归因与解释

- 确定归因："这是由于"
- 推测："这可能与……有关"
- 不用"这是因为"堆叠

## 句式

### 数据比较

- 先给整体趋势，再给具体数字
- 接近写"相差不大"或"差值不超过 X 个百分点"
- 本文不作显著性结论，正文不写"差异显著""无显著差异"；逐路径计数只作描述（"在 12 条路径中的 10 条上最低"），不解释为独立重复试验
- "排序一致"须写明口径，如"按 12 条路径的平均值"
- 泛化退化比例较小不等于泛化能力更强，写"泛化退化比例较小不代表跨站绝对精度更高"，不写"比例小是因为基准低"
- 弱者用"而"引出："U-TAE 和 3D U-Net 在各站点均高于 ConvGRU，而二者之间差值不超过 1 个百分点"

### 图表引用

- 首选："如图 X 所示""如表 X 所示"
- 句中括注："（表 2）"
- 图表在正文中先引用，后出现

### 过渡

- 不使用机械过渡词（"首先、其次、再次、最后"）
- 逻辑衔接："在……基础上，本文进一步……""上述结果表明……"

## 禁止的表达

| 禁止 | 替代 |
|---|---|
| "较高的精度""较为接近" | 直接给数字范围，不加空洞修饰 |
| "共同的分类特征" | "两点共性"或直接列事实 |
| "在本研究的数据划分下" | 删（折间标准差本身就是在你的划分下算的） |
| "从……来看""从……角度" | 直接说论点 |
| "本文创新性地提出" | 除非确实有创新 |
| "值得注意的是" | 除非真正值得注意 |
| "综上可知" | 只用在段尾或节尾总结 |
| "统计学上的显著差异""差异显著""无显著差异" | 本篇不作显著性结论；按明确的对象与口径报告数值差异 |
| "基于……的……"堆叠 | 拆成两句 |
| "进行……处理" | 直接用动词 |
| 空壳强调句 | 删 |

## 方法描述

- 对模型结构偏详细，包含数学公式
- "由……组成""通过……实现"
- 每个 equation 环境只放一个公式、一个编号

## 参考论文的写法

五篇同领域中文核心期刊论文的摘录与分析在 `bibliography/writing-style-report.md`。用法：
- 学**概念阐述方式**（泛化能力怎么定义、迁移怎么称呼）和**结果段从数字到解释的衔接**
- 不照搬呈现形式：本文保留跨站绝对 F1 + 泛化退化比例 DR、完整跨站 F1 表、六子图热力图和中文角标；百分点差值文件仅供追溯，不恢复为正文指标
