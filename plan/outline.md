## 0 引言

粮食安全与作物空间分布制图
→ 玉米大豆光谱相似性 → 多时相观测必要性
→ 时空深度学习三类范式（压缩介绍）
→ 现有研究集中于特定区域，缺乏跨区域泛化系统评价
→ 跨区域泛化不仅涉及模型差异，还涉及区域空间结构差异
→ 需要从空间特征角度解释泛化差异

研究目标：在统一实验条件下，以严格 OOF 评价建立站内基准，通过完整目标域测试和配对检验比较三类模型的玉米、大豆跨区域识别能力，进一步从站点与 Patch 两个尺度分析泛化差异的区域依赖性。
