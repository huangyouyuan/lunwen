# 论文大纲

## 0 引言

粮食安全与作物空间分布制图
→ 玉米大豆光谱相似、单时相难分 → 多时相观测必要（E3 黄健熙）
→ 时空深度学习三类范式（压缩介绍）
→ 现有研究多在单一区域训练测试；有效识别信息有区域差异（E4 沈宇），空间组织与时序信息共同参与识别（E5 张冬韵）
→ 已有跨区域研究表明泛化受地块尺度、种植结构影响（E1 盖爽、E2 张凤），但未在统一条件下比较不同时空建模方式各自受影响的程度
→ 本文研究问题

研究目标：在统一数据和实验条件下，以站内汇总精度为基准，通过完整目标站测试，比较三种时空模型的玉米、大豆跨站绝对精度与泛化退化比例，进一步在统一图块单元上分析各模型退化与地物占比、景观指标的对应关系。

## 3 实验结果与分析

### 3.1 模型站内分类性能
- 站内汇总玉米 F1、大豆 F1、OA
- 五折均值 ± 标准差说明训练稳定性
- 三模型排序、玉米/大豆难度差异、站点难度差异

### 3.2 模型跨站分类性能与泛化退化
- 12 条迁移路径完整精度表：三模型的玉米、大豆跨站 F1；末行给出路径平均
- 第一段：跨站绝对 F1，36 个模型—路径组合全部低于目标站站内基准，跨站 F1 高低与目标站有关
- 第二段：按路径平均的跨站 F1 排序与平均泛化退化比例排序的区别；比例较小不代表跨站绝对精度更高
- 第三段：六子图热力图；源—目标组合与迁移方向差异，引出 3.3 两个问题
- 不作显著性检验；路径计数只作描述

### 3.3 模型跨站泛化差异的空间解释
- 问题一：目标站在哪些空间条件下退化较大
- 问题二：同一目标站的退化随源站而变化，这种变化与站点间哪些差异相对应
- 覆盖全部站点与 12 条路径；站点级与图块级分析；图块分组后汇总混淆矩阵计算分类结果
