# 总体论文计划

本文件规定章节分工和推进顺序。研究逻辑见 [paper-context.md](paper-context.md)，证据路由见 [results-map.md](results-map.md)，进度见 [progress.md](progress.md)。`tasks/`只保存活动执行安排。

## 当前主线

在统一条件下，比较三模型跨站绝对F1和相对目标站本站基准的差距，再把具体差距连接到错分变化及目标空间条件。景观指标用于描述和条件对照，现有证据不证明机制。

| 章节 | 主要问题 | 边界 |
|---|---|---|
| 1.3研究区空间特征 | 四站组成、完整参考斑块与整站格局怎样不同 | 不由参考分布预判精度或退化 |
| 3.1本站分类性能 | 当地训练基准及主要漏分、误分入方向 | 不展开跨站增量 |
| 3.2跨站分类性能 | 绝对F1、原尺度ΔF1及模型—来源—目标差异 | 不作无证据归因 |
| 3.3空间解释 | 具体差距对应什么错误、空间条件及模型来源变化 | 不把描述性对应写成独立效应或因果机制 |

先完成 [1.3与3.1基础材料计划](tasks/2026-10-10-sec13-sec31-foundations.md)，再从3.2选择3.3证据。3.1只作必要补充，3.2保持。共同分级和联合分析不是当前必经步骤。

## 章节安排

| 章节 | 内容 |
|---|---|
| 引言 | 作物制图、时序建模、跨区域局限及本文问题，按文献证据组织 |
| 1.1、1.2 | 四站范围、HLS与CDL、2023年处理流程 |
| 1.3.1地物组成 | 整站三类参考面积与占比，分母为有效参考像元 |
| 1.3.2景观格局 | 四站三类地物的一张表分斑块级、类别级、景观级；AREA、SHAPE以斑块等权中位数（最小值～最大值）呈现，PD、AI为类别级，ED为整站值；“其它地类”是多类合并的参考类别。图2置于1.3.1与1.3.2之间，表1置于1.3.2与第2节之间 |
| 2.1模型 | U-TAE、3D U-Net、ConvGRU及必要原理 |
| 2.2实验设计 | 五折本站与五次完整目标站迁移，不作显著性检验 |
| 2.3、2.4 | 作物F1与OA、统一训练条件和配置 |
| 3.1 | 现有F1比较、折间波动、D站示例和必要的本站错分 |
| 3.2 | 完整12路径表、模型均值及固定目标来源/方向差异 |
| 3.3 | 从3.2连接漏分、误分入、位置和参考空间条件，先全量后实例 |
| 4结论、摘要 | 内容确定后只概括有证据支持的结果 |

结果章3.1—3.3不设第三级标题。参考连通斑块不是农业田块，128×128图块仅用于训练与预测追溯。斑块内漏分率不能命名为等级F1。
