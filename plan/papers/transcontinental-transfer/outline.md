## 0 引言

玉米—大豆制图与标签样本成本
→ 多时相遥感信息对两类作物识别的必要性
→ 深度学习模型通常依赖训练区，跨区域特别是跨洲应用面临物候、光谱与农业景观差异
→ 现有研究已经证明美国标签和模型向中国迁移具有可行性，但不同目标区、年份和时空建模方式的损失及适用条件仍需统一比较
→ 提出 Q1 和 Q2，并限定为嫩江、北安及覆盖年份的诊断研究

引言正式写作前必须重建 evidence map 和 chapter blueprint。

- 中国东北目标区：嫩江、北安

### 1.2 遥感数据与标签

- 2020—2023 年嫩江、北安数据覆盖情况

### 1.3 时序与空间特征

## 2 研究方法

### 2.1 时空深度学习模型

ConvGRU、3D U-Net、U-TAE。保留统一输入、输出与训练配置，模型介绍服务于三种时空建模方式的比较，不宣称提出新模型。

### 2.2 实验设计

#### 2.2.1 东北本地训练基准与美国来源模型

- 嫩江、北安各年份本地交叉验证
- 本地基准与跨洲迁移必须使用可比的目标区评价范围和指标口径
- 美国来源模型的数据集、折和权重身份审计；美国本地精度只作有效性说明

#### 2.2.2 美国至中国东北的跨洲迁移

- 美国训练模型直接评价嫩江、北安各年份
- 不使用东北样本微调的主实验
- 源域组合、单站或多站训练方案及配对单位待实验矩阵确认

#### 2.2.3 额外迁移损失与统计比较

- 额外迁移损失以同模型、同目标区、同年份的东北本地训练结果为基准
- 分别报告玉米 F1 和大豆 F1
- 模型、作物、目标区和年份的比较需处理重复来源与非独立性，不能直接沿用旧 12 路径检验

### 2.3 退化诊断指标

- NDVI 时序差异：指标待数据检查后确定，可考虑关键物候阶段差异、曲线距离或时间错位；不得先定结论
- 空间结构差异：地物组成、边界密度、平均斑块面积、聚集度等候选指标
- 诊断分析报告关联与分层规律，不预先承诺因果贡献率

### 2.4 精度指标与实验环境

保留混淆矩阵、玉米 F1、大豆 F1 和 OA 的计算方式；统计单位和汇总层级按新实验设计重写。

## 3 结果与分析

### 3.1 东北本地训练表现

回答三种模型在嫩江、北安各年份使用当地样本训练时能达到什么水平，建立跨洲比较的目标域基准。第一段讲三种模型的共同表现，第二段讲模型差异；美国本地结果不在本节重复展开。

### 3.2 跨洲迁移能力与性能差距

直接回答 Q1：报告美国训练模型在嫩江、北安各年份的绝对 F1，并与相同目标区、年份的本地训练基准比较。分析模型、作物、目标区和年份之间的一致与不一致。

### 3.3 退化规律与适用条件

直接回答 Q2：把额外迁移损失与 NDVI 时序差异、空间结构差异对应起来，分析三种模型在本地训练中的相对优势跨洲后是否保留。结论写成诊断关系和适用条件；只有证据充分时才讨论机制。
