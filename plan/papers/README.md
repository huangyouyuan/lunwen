# 双论文管理

当前项目分为两篇证据边界独立的论文，按顺序推进。

## 当前活动论文

`spatial-generalization`：美国 4 站点 2023 年三种时空深度学习模型的站内表现、跨站退化及空间差异解释。顶层 `plan/`、`sections/`、`results/`、`tables/` 和现有结果图均服务于该文。

## 后续论文

`transcontinental-transfer`：美国训练模型直接迁移至嫩江、北安，与东北本地训练模型比较，并诊断 NDVI 时序和空间结构差异对应的额外迁移损失。固定框架保存在 `plan/papers/transcontinental-transfer/`，待第一篇完成后恢复为活动计划。

## 证据边界

- 美国站内和美国站间结果属于空间泛化篇，不能表述为跨洲证据。
- 跨洲篇的核心对照是东北本地训练与美国模型直接迁移；美国本地结果只用于说明来源模型有效性，不重复作为主要结果展开。
- 两篇可以共享模型实现、数据预处理和评价方法，但不得复用结果段落、核心图表或把同一结果包装为两项独立发现。
- 若两篇投稿或发表时间重叠，方法复用和前文关系须按期刊规范披露、引用。

## 推进顺序

1. 完成空间泛化篇 3.2、3.3、引言、方法复核、结论和摘要。
2. 投稿空间泛化篇后，切换活动计划至跨洲篇。
3. 修复东北数据生产链，重建逐年数据集，再运行东北本地训练和美国至东北直接迁移。
